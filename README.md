# ỨNG DỤNG ÔN LUYỆN VIẾT LẠI CÂU TIẾNG ANH 8 - GIỮA KÌ 1

> **Chủ đề:** 40 câu viết lại câu cơ bản giữ nguyên nghĩa với từ gợi ý  
> **Thời gian làm bài:** 20 phút  
> **Đặc điểm nổi bật:** Tự động chấm điểm, đếm ngược thời gian, mở khóa đáp án & giải thích chi tiết sau khi nộp bài.

---

## 🌟 Tính Năng Nổi Bật

1. ⏱️ **Đồng hồ đếm ngược 20 phút (Countdown Timer):**
   - Có thanh tiến độ thời gian trực quan.
   - Cảnh báo chuyển màu đỏ & nhấp nháy khi còn dưới 3 phút.
   - Tự động thu bài và chấm điểm khi hết 20 phút.
   - Có nút tạm dừng / tiếp tục tiện lợi.

2. 🔒 **Bảo mật đáp án tuyệt đối:**
   - Trong lúc làm bài, đáp án và lời giải hoàn toàn được ẩn.
   - Chỉ mở khóa xem đáp án và phân tích ngữ pháp chi tiết sau khi học sinh bấm **"Nộp bài"** hoặc **khi hết thời gian 20 phút**.

3. 🎯 **Chấm điểm thông minh & Linh hoạt:**
   - Tự động chuẩn hóa dấu câu, khoảng trắng thừa, chữ hoa/chữ thường, dấu nháy đơn `'`.
   - Hỗ trợ các biến thể ngữ pháp chuẩn (ví dụ: `would rather drink` / `would rather have`, `in order to` / `to`, v.v.).
   - Thang điểm 10 và số câu đúng / 40.

4. 📖 **Phân tích ngữ pháp chi tiết từng câu:**
   - 📌 **Công thức áp dụng:** Nêu rõ cấu trúc gốc và cấu trúc viết lại.
   - 💡 **Phân tích chi tiết:** Giải thích vì sao chọn thì, dạng động từ, tân ngữ, giới từ.
   - 📖 **Dịch nghĩa:** Giúp học sinh hiểu sâu bản chất câu.

5. 🔊 **Hỗ trợ phát âm tiếng Anh (Text-to-Speech):**
   - Học sinh có thể nhấn nút loa để nghe giọng đọc bản xứ cho cả câu gốc và câu đáp án.

6. 🗺️ **Mục lục 40 câu điều hướng nhanh:**
   - Hiển thị trực quan trạng thái câu (chưa làm, đã làm, đúng, sai).
   - Nhấn vào số câu bất kì để cuộn nhanh đến câu đó.
   - Phím tắt `Enter` tự động chuyển sang câu tiếp theo.

7. 🖨️ **In đề & Phiếu kết quả chuẩn A4:**
   - Tích hợp sẵn nút "In / Xuất PDF" định dạng trang in sạch sẽ cho giáo viên hoặc phụ huynh lưu trữ.

## 🚀 Hướng Dẫn Đưa Lên GitHub & Chạy Trực Tiếp (GitHub Pages)

Dự án là một **Single Page Application (SPA)** thuần túy (`index.html`), sử dụng CDN trực tuyến, không cần cài đặt Node.js hay build code.

### Cách 1: Tải trực tiếp qua giao diện web GitHub (Đơn giản nhất - 1 phút)

1. Đăng nhập vào tài khoản [GitHub](https://github.com/).
2. Nhấn nút **New Repository** (Tạo repo mới):
   - Đặt tên Repository, ví dụ: `tieng-anh-8-viet-lai-cau`.
   - Chọn chế độ **Public**.
   - Nhấn **Create repository**.
3. Tại trang repo vừa tạo, chọn **"uploading an existing file"** (tải lên file có sẵn).
4. Kéo thả file `index.html` và `README.md` vào ô tải lên, sau đó nhấn **Commit changes**.
5. Kích hoạt **GitHub Pages**:
   - Vào mục **Settings** (Cài đặt của Repo).
   - Ở thanh menu bên trái, chọn **Pages**.
   - Tại mục **Build and deployment** -> **Source**: Chọn **Deploy from a branch**.
   - Chọn nhánh **`main`** (hoặc `master`), thư mục **`/(root)`**, rồi nhấn **Save**.
6. Đợi khoảng 30 giây đến 1 phút, GitHub sẽ cung cấp link website trực tiếp của bạn:
   ```
   https://<ten-tai-khoan-github>.github.io/tieng-anh-8-viet-lai-cau/
   ```
   *Bất kì ai có link này (trên máy tính hay điện thoại) đều có thể truy cập và làm bài thi trực tuyến ngay lập tức!*

### Cách 2: Sử dụng lệnh Git (Dành cho lập trình viên)

```bash
# Khởi tạo git và commit
git init
git add .
git commit -m "Khoi tao web luyen viet lai cau Tieng Anh 8 Giua Ki 1"
git branch -M main

# Liên kết với repo GitHub của bạn
```
